# Motion Ad Studio

10초·30초 생성형 모션광고를 기획하고, 장면별 스토리보드와 Google Flow 등 영상 생성 도구에 사용할 영문 프롬프트를 만드는 한국어 웹앱입니다.

## 현재 기능

- 10초 광고 자동 구성: HOOK → ACTION → TRANSFORMATION → BRAND
- 30초 광고 자동 구성: 1편 문제/공감 → 2편 해결/기능 → 3편 가치/브랜드
- 30초 광고를 10초씩 별도 생성하도록 프롬프트 분리
- 창업경진대회 앱 광고 프리셋
- 기준 이미지 브라우저 미리보기
- 캐릭터 일관성 잠금 프롬프트
- 한국인 캐릭터 우선 옵션
- 프롬프트 밀도 선택
- 한글 자막 직접 생성 방지
- 후편집용 한글 자막 스크립트
- 장면별/전체 프롬프트 복사
- 전체 결과 TXT 다운로드
- 프로젝트 브라우저 저장 및 불러오기
- 생성 전 체크리스트

## 권장 제작 흐름

1. 광고 목적과 브랜드 정보를 입력합니다.
2. 10초 또는 30초를 선택합니다.
3. 동일 인물을 유지해야 하면 기준 이미지를 첨부합니다.
4. 캐릭터 일관성 잠금을 켭니다.
5. 생성 결과에서 각 장면의 영문 프롬프트를 복사합니다.
6. 30초는 1편·2편·3편을 각각 10초로 생성합니다.
7. 영상 생성 단계에서는 한글 자막을 넣지 않습니다.
8. 완성 영상에서 후편집용 한글 자막을 합성합니다.

## 개인정보 및 이미지 처리

현재 버전에서 선택한 기준 이미지는 브라우저의 로컬 미리보기 용도로만 읽습니다. 외부 서버로 전송하지 않으며 localStorage 저장본에도 이미지 원본을 넣지 않습니다.

## 실행

정적 웹앱이므로 별도의 빌드 과정 없이 `index.html`을 웹 서버에서 열면 실행할 수 있습니다. GitHub Pages와 같은 정적 호스팅에 적합합니다.

## 다음 개발 단계

- 서버 기반 AI 프롬프트 생성 API
- 사업계획서/PDF 핵심 내용 분석
- 한 프로젝트 안에서 여러 광고 버전 저장
- 장면별 이미지 생성 프롬프트와 영상 프롬프트 분리
- 실제 생성 영상 링크/파일 관리
- 브랜드 스타일 프리셋
- 교육/창업/퍼스널 브랜딩 전용 템플릿 확장

## API 보안 원칙

AI API를 연결할 때 API 키를 브라우저 JavaScript 코드에 직접 넣지 않습니다. 서버 환경변수 또는 안전한 서버리스 API를 통해 호출하도록 구성해야 합니다.
